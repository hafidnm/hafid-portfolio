# Hafid Nur Mahmudi - Personal Portfolio

A modern, responsive, dynamic personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS.

## 🚀 Tech Stack
- **Frontend Framework:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
